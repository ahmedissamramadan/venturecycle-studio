# VentureCycle Studio - Official Landing Page & Digital Agency Hub (v3)

نظام تشغيلي متكامل لابتكار الهوية البصرية، المحتوى التسويقي، وأتمتة العمليات بالذكاء الاصطناعي للشركات B2B في الشرق الأوسط.

## 🚀 تفاصيل الصفحات المضمنة
1. **الصفحة الرئيسية (index.html):** تحتوي على خدمات الاستوديو، معرض أعمال B2B بستة مشاريع حقيقية مع كروت توهج، الأرشيف الزجاجي للمسودات، لوحة المحاكاة التفاعلية (AI Sandbox)، والأسئلة الشائعة بنظام السكيما.
2. **حاسبة العائد الاستثماري (roi-calculator.html):** أداة متقدمة لحساب الوفر الوقتي والمالي السنوي وتوليد رسالة واتساب ديناميكية للتواصل المباشر.
3. **المدونة الاستراتيجية (blog.html):** صفحة مهيأة بالكامل بأكواد JSON-LD و Microdata لتتصدر إجابات محركات البحث ومحركات الإجابة بالذكاء الاصطناعي (AEO).

## 🛠️ البنية التقنية والأداء
- **اللغات:** HTML5, Vanilla CSS3 (Custom Variables & HSL), Client-side JavaScript.
- **الأداء:** تم تفعيل وسم preloading للخطوط وتخفيض الأصول المعيقة للرسم لرفع كفاءة سرعة الرسم الأولية LCP.
- **التوافق:** متجاوب بالكامل مع الشاشات والأجهزة اللوحية ويدعم الوضعين الداكن والمضيء لحفظ تفضيل المستخدم.

## 📦 خطة النشر والـ CI/CD
يحتوي المشروع على ملفات الإعداد القياسية:
- `robots.txt` لتنظيم الزحف وعناكب الذكاء الاصطناعي.
- `sitemap.xml` لتعريف الهيكل البرمجي للموقع.

### كيفية النشر السريع (Deployment)
المشروع عبارة عن تطبيق ثابت (Static Site)، لذا يمكن نشره مجاناً وفوراً عبر:
1. **GitHub Pages:**
   قم برفع هذا المجلد لـ GitHub وتفعيل خيار GitHub Pages من إعدادات المستودع (Settings -> Pages).
2. **Vercel / Netlify:**
   قم بتشغيل الأمر `vercel` أو ربط المستودع بمنصة Vercel للرفع التلقائي مع كل push.
